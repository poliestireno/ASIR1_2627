# RA12_FOTOS_VARIAS

## ENUNCIADO

Galería de fotos con HTML puro, para practicar estructura y tablas.

Teoría de referencia (pública): `teoria-html-fundamentos.html`.

### Enunciado

Realiza una web con 4 páginas para ver fotos — es importante la **disposición** en la que están colocadas las imágenes. El tema es libre.

### Se pide

- Todas las imágenes se podrán ver solas, en otra pestaña (enlace directo a la imagen).
- Cada subpágina tendrá un enlace para volver a la página principal (la página con el índice).
- Cada imagen lleva un texto corto debajo.

**Pista:** una forma cómoda de organizar la disposición de las imágenes es con `<table>`.

**FIN ENUNCIADO**

## DESAFÍO NCA

**Desafío Nº:** `RA12_FOTOS_VARIAS`

# Una galería de fotos en HTML puro: la disposición cuenta tanto como el contenido

Diseñar y maquetar con HTML puro una galería fotográfica de 4 páginas, usando tablas para controlar dónde va cada imagen.

### Objetivos técnicos

- Construir una galería de 4 páginas HTML enlazadas entre sí a partir de una página índice.
- Usar tablas HTML para maquetar la disposición de las imágenes dentro de cada subpágina.
- Enlazar cada imagen a su versión a tamaño completo, abierta en una pestaña nueva.
- Añadir un texto corto bajo cada imagen.
- Implementar en cada subpágina un enlace de vuelta a la página índice.

### Módulos implicados

- CFGS Administración de Sistemas Informáticos en Red – ASIR, módulo Lenguajes de Marcas (MAR)

### Resultados de aprendizaje

- **RA1.** Reconoce las características de lenguajes de marcas analizando e interpretando fragmentos de código.
- **RA2.** Utiliza lenguajes de marcas para la transmisión de información a través de la Web analizando la estructura de los documentos e identificando sus elementos.

### Elementos transversales / competencias

Organización visual de la información, atención al detalle, creatividad, documentación técnica

### Principios pedagógicos

Construcción del pensamiento, Aprendizaje por proyectos, Autonomía

### Sesiones

Acogida 1 · Explorar 1 · Idear 1 · Materializar 3 · Cierre 1 — **Total: 7 sesiones en 7 días**

---

### Fases

**Acogida** — 1 sesión
- Presentación del desafío: crear una galería de fotos propia en HTML puro, donde la disposición de las imágenes importa tanto como las imágenes en sí.

Observación: primer proyecto visual tras los fundamentos de HTML y CSS, con el tema de la galería totalmente libre.

**Explorar** — 1 sesión
- Repasar cómo estructurar una tabla HTML (`<table>`, `<tr>`, `<td>`) para maquetar disposiciones de contenido — pond. 2
- Repasar cómo enlazar una imagen a su propio archivo para que se abra en una pestaña nueva, y cómo enlazar entre páginas distintas de un mismo sitio — pond. 1

Observación: apoyado en la teoría de referencia del módulo sobre fundamentos de HTML.

**Idear** — 1 sesión
- Elegir el tema libre de la galería y repartir las fotos entre las 4 páginas, bocetando la disposición de cada una (filas y columnas de la tabla) — pond. 2
- Redactar el texto corto que acompañará a cada imagen — pond. 1

Observación: se piensa la disposición y el contenido antes de escribir ningún HTML.

**Materializar** — 3 sesiones
- Crear la página índice con los enlaces a las 4 subpáginas — pond. 1
- Maquetar cada subpágina con `<table>`, colocando las imágenes según lo bocetado en Idear, con su texto corto debajo de cada una — pond. 3
- Enlazar cada imagen a su versión a tamaño completo en pestaña nueva, y añadir en cada subpágina el enlace de vuelta al índice — pond. 2

Observación: es la fase central — se evalúa tanto que la disposición funcione visualmente como que se cumplan los tres requisitos técnicos del enunciado (enlace directo a la imagen, vuelta al índice, texto bajo cada imagen).

**Cierre** — 1 sesión
- Puesta en común mostrando la galería de cada alumno, comparando las distintas disposiciones elegidas para el mismo reto.

Observación: comparar soluciones distintas al mismo problema de maquetación, con temas de galería diferentes entre alumnos.
